# Python-To-Do-List-Application
A simple command-line based To-Do List application developed in Python as part of Project 1 during the Python Programming Industrial Training at DecodeLabs.

🚀 Features:
- Add new tasks
- View all saved tasks
- Simple and user-friendly menu system
Task management using Python Lists
Beginner-friendly Python project
🛠 Technologies Used
- Python 3
📚 Concepts Used
- Python Lists
- Loops
- Conditional Statements
- User Input Handling
- List Operations (append)
- Program Flow Control
